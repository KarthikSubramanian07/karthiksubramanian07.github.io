# Accessibility Statement

This website targets conformance with the **Web Content Accessibility Guidelines (WCAG) 2.2 Level AA**.

## Accessibility Features

- **Keyboard Navigation & Skip Links (WCAG 2.1.1, 2.4.1):** All interactive controls and external navigation routes are fully operable by keyboard. Visible skip-to-content links allow bypassing repeated headers.
- **Focus Visibility (WCAG 2.4.7, 2.4.11):** All focusable components provide distinctive, high-contrast `:focus-visible` indicators.
- **Color Contrast (WCAG 1.4.3):** Text, icons, and interactive elements across all views maintain at least 4.5:1 contrast against their surfaces (or 3:1 for large text).
- **Label in Name (WCAG 2.5.3):** Controls and links maintain accessible names matching their visible labels to support voice navigation and speech input.
- **Reduced Motion (WCAG 2.2.2, 2.3.3):** All ambient canvas and CSS animations honor the user's `prefers-reduced-motion: reduce` system preference.
- **Semantic Structure & Landmarks (WCAG 1.3.1, 2.4.6):** Logical heading hierarchy (`h1` through `h4`) and native HTML landmarks (`main`, `nav`, `header`, `footer`) structure every document.
- **Alternative Formats:** Every HTML page is paired with an alternate clean Markdown document for script-free and terminal browsing.
